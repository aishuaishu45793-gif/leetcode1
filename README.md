## 💻 How to Run the Code

### 1. Install Python

Check whether Python is installed:

```bash
python --version
```

or:

```bash
py --version
```

### 2. Clone the Repository

```bash
git clone https://github.com/aishuaishu45793-gif/leetcode1.git
```

### 3. Open the Project in VS Code

Open the `leetcode1` folder in Visual Studio Code.

### 4. Run a Python File

For example:

```bash
python hello.py
```

or:

```bash
py hello.py
```

You can also use the **Run Python File** button in VS Code.
